# CodeAlpha_Iris-Flower-Classification
# 🌸 Iris Flower Classification using Machine Learning

## 📌 Project Overview

This project focuses on classifying Iris flowers into three different species using Machine Learning techniques.

The model predicts the flower species based on four measurements:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The project uses the Iris dataset provided by Scikit-learn and implements the Logistic Regression algorithm for classification.

## 🎯 Project Objective

The main objective is to build a Machine Learning model that can accurately identify Iris flower species based on their physical measurements.

## 🌼 Iris Flower Species

The model classifies flowers into three categories:

1. Setosa
2. Versicolor
3. Virginica

## 🤖 Machine Learning Algorithm

**Logistic Regression**

Logistic Regression is a supervised Machine Learning algorithm used for classification problems.

In this project, it predicts whether an Iris flower belongs to Setosa, Versicolor, or Virginica.
